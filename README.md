# JoSAA Historical Cutoff Dataset (2018–2025)

A structured historical dataset of **JoSAA opening and closing ranks** covering **2018–2025**.

The dataset brings together years of JoSAA admission data into a single machine-readable CSV, making it easier to analyze cutoff trends, compare institutes and programs, and build admission analytics or prediction projects.

## 📊 Dataset Coverage

**Years:** 2018–2025

The dataset contains information related to:

- Institutes
- Academic programs / branches
- Opening ranks
- Closing ranks
- Categories / seat types
- Gender
- Counselling rounds
- Other available JoSAA admission fields

## 📁 Dataset

The main dataset is:

`cutoffsfinal.csv`

The CSV can be directly imported into:

- Python / Pandas
- R
- Excel
- SQL databases
- Data visualization tools
- Machine learning pipelines

## 💡 Possible Applications

This dataset can be used for:

- 📈 Historical cutoff trend analysis
- 🎓 College and branch comparison
- 🔎 Rank-based college prediction
- 📊 Admission analytics
- 🤖 Machine learning experiments
- 🌐 JoSAA college predictor applications
- 📉 Year-over-year cutoff analysis
- 🏫 Institute and program research

## 🧪 Example Analysis

With this dataset, you can answer questions such as:

> How has the closing rank of a particular branch changed between 2018 and 2025?

> Which institutes had the largest cutoff changes over the years?

> What colleges and branches historically accepted a particular rank?

> How do different categories and counselling rounds affect closing ranks?

## 📚 Data Source

The data is based on publicly available **JoSAA opening and closing rank information**.

This project is **not affiliated with or endorsed by JoSAA**.

## ⚠️ Disclaimer

Historical cutoff data should not be interpreted as a guarantee of future admission outcomes. Cutoffs can vary based on factors such as applicant preferences, seat availability, category, gender, counselling round, and year.
